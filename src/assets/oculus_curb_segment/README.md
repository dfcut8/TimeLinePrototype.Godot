# Oculus curb segment — #22

Reusable 15-degree overhead curb sector, 10–10.6 m radii and 0.6 m height.
Twenty-four instances form an open oculus. Room-centre pivot at the underside,
sector centred on +X; Godot +Y up. 396 triangles, two embedded matte materials.

Instance `oculus_curb_segment.tscn`; it owns the GLB and beam attachment marker.
Editable source is `source/oculus_curb_segment.blend`.
